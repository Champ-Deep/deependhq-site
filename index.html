How a day becomes an entry.

The window runs 3 PM to 2 AM IST. At 2 AM the site publishes itself.

how a day becomes an entry

15:00

IST, inside the working window

  1. 15:00

    Calls first.

    Client, vendor and partner calls fill the afternoon. Each one lands in the vault as a note, or it did not happen.

    ls vault/Calendar/Meetings | tail -1

    2026-09-29 enterprise IT services client.md

    + 10-day trial instead of a walkout · daily updates · shared sheet

  2. 19:00

    Build what the calls exposed.

    If a call surfaced a gap, it gets built that night, without a ticket or a slot on a roadmap.

    git push origin main

    141 files changed · 56 backend tests green

    end-to-end run passed twice

  3. 23:00

    Write it down, unedited.

    The daily note is the raw material: what shipped, what it connects to, what I think.

    open vault/Calendar/Daily/2026-09-30.md

    shipping_now · yesterday_thread · raw_thought · arcs

  4. 01:03

    An agent compiles the entry.

    A nightly agent reads the note, writes the entry and rebuilds every number on this page from source. Nothing is typed in by hand.

    node scripts/build-data.mjs

    day 342 · 120 entries · 16 essays · 12 companies

    data.js written · built 9 Oct 03:09 IST

  5. 02:00

    Live by 2 AM.

    It pushes, the Cloudflare Worker serves it, and when an entry is late the top of the site says so.

    bash scripts/publish.sh

    deploy ok · deependhq.com

    next window opens 15:00 IST
