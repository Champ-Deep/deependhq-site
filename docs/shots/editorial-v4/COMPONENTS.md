Preview only. Deep has NOT approved v4. No publication is requested.

## Mounted source versus composition

The installed A11YPros Accessible Accordion details/summary structure, content classes and chevron are build-rendered for all twelve companies. The installed ln-dev7 Footer17 compact navigation/legal-row composition is adapted to the existing footer links. The prior installed nextjsshop Arrow Dots Button remains the hero CTA with twenty rendered dots. The existing Kokonut Activity Terrain remains the only homepage React island. These are the actual source adoptions.

Other rows below are research selections for discussion, not claims that all nine registry components were installed or mounted. Native editorial composition and existing house components avoid adding runtime packages, invented imagery and new animations just to use a catalog item. The Activity Feed registry dependency was unavailable. Spotify installation failed with npm EALLOWSCRIPTS twice; no Spotify component is falsely claimed as installed. Its visible fallback is native markup with service-like weight, tracking and honest disconnected status. Spotify Circular and PlayStation SST are not installed or claimed. No accounts or credentials were created.
