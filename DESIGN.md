# DeepEndHQ editorial v4 preview: a working field guide

## 1. Visual Theme and Atmosphere
Identity, useful tools, one latest dispatch, then the machinery behind it. This replaces the rejected sequence, not just its skin. Tool entry points sit directly below the hero. Companies become a numbered directory, writing a weekly edition, and off-hours a compact listening / playing shelf. This is an isolated proposal. Deep has NOT approved v4.

## 2. Color Palette and Roles
Dark: terminal #09140D ground, #102117 surface, #172D1E card, #203925 raised card. Text #EDF5DC, muted #BED2B5, dim #ACBEA2. Terminal green #71F394 and gold #E6BD60 have separate jobs: tools/machinery versus editorial/actions. Light: buttery #F7EDCE, espresso #30291F, antique gold #795515, olive #48612B. Large olive tool shelf and antique-gold edition marker make the accents structural rather than tiny badges. system.css is canonical; scheme-tokens.css is generated. User feedback explicitly supersedes the prior black/charcoal proposal.

## 3. Typography Rules
Fraunces variable display for the personal name and statement, Inter for editorial body/UI, JetBrains Mono for log data. The name anchors the cover without consuming the whole screen. Display uses optical size, weight, soft and wonk axes; text below 32px resets soft/wonk. Existing self-hosted font files and scales remain.

## 4. Component Stylings
Keep installed Arrow Dots booking CTA and Kokonut Activity Terrain. Replace generic folder artwork with 21st A11YPros native details/summary disclosure grammar and real company links. Replace the unreadable day select with the earlier calendar heatmap plus labelled date and previous/next controls. No decorative glass or new runtime dependency. One scheme toggle, visible focus, 44px controls. Greeting-only .dh-pro suppression stays intact. Spotify/PlayStation styling is an approximation using installed fonts, never invented account activity.

## 5. Layout Principles
1200px content width, existing 4px scale. Reading order: identity, merged tool shelf, latest entry plus three compact date-only archive links, weekly edition, company directory, seven-lane day-to-entry process and machine-log terrain, off-hours, contact, quiet footer. No mission-log dashboard under the hero. Full entries live at /journey.

## 6. Depth and Elevation
Flat terminal/paper grounds, ruled rows, solid accents. No generated marbling, glass folders, footer canvas or giant footer wordmark. Approved scouter and icon sprite remain byte-identical.

## 7. Do's and Don'ts
No invented log facts, counts, observations or terminal results. No public real team names. No generated imagery. No navy surfaces, rainbow semantic decoration, giant words alone or empty hero half. No em or en dashes in newly authored copy. No main merge, production deployment, production routes, production secrets or billing/D1 preview bindings.

## 8. Responsive Behavior
Device class: pointer and touch web. Verify 375, 768, 1280, 1600 in both schemes. Mobile order matches DOM, tool rows and directory disclosures stack, no decorative side columns. Terrain is flat below tablet and under reduced motion with a full table. Seven lanes retain the pinned desktop progression and complete static mobile/reduced fallback. Motion budget: existing finite terrain and composited interactions only. No expressive tier. All primary reading and company disclosures work without JS.

## 9. Agent Prompt Guide
Personal editorial cover, not consultancy landing page or operator dashboard. Use real roles and the latest actual log entry. Keep terrain below in the public log, preserve all six lanes. Measure contrast, targets, overflow and state changes. Deliver isolated screenshots and preview URL for visual approval only. Remaining token consumers: command, account, lead scorer, toolkit local literals, OG assets and legacy component styles require a separate approved rollout.
