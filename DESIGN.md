# DeepEndHQ combined refresh design contract

## 1. Visual Theme and Atmosphere
Editorial shell, terminal core. Deep's public operating record, not a generic agency portfolio. Preserve the approved scouter mark, mare and actual log-derived terrain. Hero/Day: P4. Log/Writing: P3. Pillars/Footer: P2. Stack/Human: P5. Public toolkit chooser/backend: P6.

## 2. Color Palette and Roles
The public site is classic only: ground #0D0F14, surface #12151D, card #181C26, text #E8E4DC, muted #A8A8A2, dim #8A8A92, build green #30E060 and outcome gold #C9A84C. Matrix Green primary and ring map to build green, not a new palette. Standalone toolkit scheme-tokens.css stays owned by the toolkit lane. No public theme switch or preference storage.

## 3. Typography Rules
Brand override: Fraunces for editorial display, Inter for UI, JetBrains Mono for operator data. Existing fluid scales and local font files remain. No unrelated font migration.

## 4. Component Stylings
The floating dock replaces the top navigation. Login is secondary to Book a Call. The homepage uses vanilla ports of 21st.dev Text Flipping Board, Squiggly Text, Encrypted Text and Pixel Art Painting Footer. Deep's scouter portrait is the dissolve subject. Primary copy and navigation are prerendered. Existing widget grid, folder cards and halftone footer retain their fallbacks. Focus stays visible; mobile actions measure at least 44px.

## 5. Layout Principles
Existing 4px spacing scale and 1200px content width below the hero. The hero pairs a split-flap headline with Deep's pixel portrait and a real latest-entry strip. Metrics live once in the Log. Mobile dock prioritizes home, disclosure, Login and Book a Call. Seven essay day links wrap into four columns on phones.

## 6. Depth and Elevation
Use existing surface ramps. Folder visuals preserve the approved interaction. Text on image sheets has opaque Ink captions. Footer privacy text has a solid scheme ground, not static decorative glass.

## 7. Do's and Don'ts
Never invent log observations, calendar activity, company metrics, auth success or provider results. Latest production day 354 and 132 entries survive. No sensitive names or disclosures. One geometry for SVG and raster identity. No generated replacement imagery. No em or en dashes in public output.

## 8. Responsive Behavior
Device class: pointer and touch web surface. Test 375, 390, 768, 1280, 1440 and 1600 in classic, including OS-light preference and reduced motion. Below tablet, the portrait stacks after the hero copy and the dock becomes a native disclosure. Motion budget: one 1.1-second introduction, canvas capped at 64 by 64 pixels, no continuous hero RAF, no blocking preloader. Reduced motion exposes the final readable state immediately. Plain document navigation preserves static reading.

## 9. Agent Prompt Guide
V3 changes the hero and public navigation only. Preserve the other approved sections, actual data, toolkit code and Worker behavior. Use classic tokens and static reading. Publish only the reviewed exact head through the downstream release card.
